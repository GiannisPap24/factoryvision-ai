# Model Card: ResNet18 feature memory, development v1

Milestone 2C, 24 October 2026. Local exploratory prototype; no official-test performance measured for this model.

**Intended use:** research on CPU feature-memory mechanics, normal calibration and synthetic localization checks. Not approved for autonomous inspection, safety/food-quality decisions, deployment or commercial redistribution. Historical autoencoder and spatial mean results remain separately documented in the unchanged 2B Model Card (source distribution: `docs/model-card.md`).

**Architecture:** frozen ImageNet V1 ResNet18 through layer3; layer2/3 local average features concatenated at 16x16 into 384 channels. Full-frame RGB128, ImageNet channel normalization, no fitted feature transform. A 5,040-patch float32 memory from 315 normal training images supports exact chunked RMS Euclidean nearest-neighbor scoring. Maximum patch distance is the image score; bilinear128 spatial maps have no calibrated pixel threshold. This is PatchCore-inspired, not an exact PatchCore reproduction. Zero parameters were optimized in 2C; the pretrained extractor contains 2,782,784 frozen parameters.

**Provenance:** official ResNet18 weight file SHA-256 `f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec`; fitted bank artifact SHA-256 `4acd638fbef5c167c5121a12adf6dd796773cf0205420f6d317ace64fee1b1b0`; immutable development recipe SHA-256 `62ebced7c38f87a73a31099895de9120dc2320a0906bf3ed7263523f13b656fa`. Weight provenance (local evidence, not distributed: `docs/evidence/resnet18-provenance.json`) and experiment methods (source distribution: `docs/feature-memory.md`) document origin, hash validation, legacy BatchNorm compatibility and rights limitations. Torchvision's BSD code license does not establish blanket pretrained-weight rights. Local research only; originals/weights/figures are ignored and unpublished.

**Data isolation:** 315 Cashew training normals fit the bank; 67 normal validation images provide diagnostic scores; 68 disjoint normal calibration images set the image threshold. Test images/masks were blocked by a development read allowlist. No Cashew official-test inference or new real-anomaly metric was calculated. Historical test metrics motivated this exploratory work and therefore cannot be reused as an unbiased selection benchmark.

**Threshold:** linear 95th percentile of normal calibration scores, strict `score > 0.08742312490940093`. Four of 68 calibration normals exceed it (5.882%, in-sample), and two of 67 validation normals exceed it (2.985%, small same-category sample). Neither is evidence of real anomaly recall; calibration exceedances are not an independent FPR estimate.

**Artificial probes:** 16 deterministic 16x16 magenta/green checkerboards inserted into the first 16 validation normals. All 16 increase scores, trigger the frozen image threshold and have a map maximum inside the artificial mask. Synthetic-only pooled pixel AUROC 0.997988 and AP 0.887513 are software/development diagnostics. They are not comparable to the autoencoder's real-test metrics and do not predict subtle industrial defect performance. Four fixed example panels illustrate broad feature responses and remain local/ignored.

**Resources:** bank tensor 7,741,440 bytes (serialized 7,743,017); feature+bank fit 3.1513s; peak fit working set 478,789,632 bytes. Ryzen 7 9700X, four Torch CPU threads, Python 3.12.15. Preloaded batch-one inference median 9.44965ms/p95 11.029735ms, five warmups/30 repeats; separate warm-cache decode/resize median 7.594ms/p95 8.07391ms. These exclude startup and camera I/O. See methods for separate extraction/search timings.

**Limitations:** one category and recipe, no real anomaly validation, deliberately conspicuous pseudo-defects, nonrepresentative synthetic locations, coarse 16x16 feature geometry, full-frame 128 resizing, ImageNet domain shift, random subsampling rather than a representative coreset, unverified physical-item/acquisition independence, alignment-sensitive duplicate screening and small calibration/validation counts. Runtime bounds are for this prototype, not arbitrary-scale deployment. Hashes prove local consistency, not signed model authenticity. The Python audit guard is not an OS sandbox.

**Decision:** mechanics and bounded CPU operation are demonstrated; real industrial detection/localization remains unestablished. A separately authorized student-teacher development proposal (source distribution: `docs/student-teacher-proposal.md`) and untouched-category confirmation design (source distribution: `docs/protocols/pcb1-confirmatory-v1.md`) define possible follow-up. No new training, pcb1 evaluation, API, GPU installation or deployment is authorized by these documents.
